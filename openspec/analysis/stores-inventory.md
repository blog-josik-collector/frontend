## 초기화·삭제

- React Query 전역 `QueryClient`는 `src/App.tsx`에서 기본 옵션으로 생성된다.
- 명시적 전체 초기화는 없다.
- 로그아웃과 회원 탈퇴는 토큰을 제거하고 내 정보 query를 제거한다.
- provider/source 삭제는 해당 detail query를 제거한다.
- Zustand store에는 별도 reset action이 없다.
