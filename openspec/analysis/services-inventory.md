# Services Inventory

## 공통 HTTP 클라이언트

| 파일                  | Export               | 동작                                                                       |
| --------------------- | -------------------- | -------------------------------------------------------------------------- | --- | ------------------------------------- |
| `src/services/api.ts` | `apiClient`, `api`   | `VITE_API_BASE_URL                                                         |     | '/'`, 10초 timeout, JSON Content-Type |
| `src/services/api.ts` | request interceptor  | `localStorage.accessToken`이 있으면 `Authorization: Bearer {token}` 추가   |
| `src/services/api.ts` | response interceptor | 오류 로깅. 401이면 access token 삭제 후 `/login` 이동, 403/500은 콘솔 기록 |
| `src/services/api.ts` | `handleApiError`     | Axios 오류를 `{message,status,code}`로 정규화                              |
